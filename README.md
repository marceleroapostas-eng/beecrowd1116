# Beecrowd 1116 - Dividindo X por Y

## Descrição
Programa desenvolvido em Java para calcular a divisão entre dois números inteiros, verificando se a operação é possível.

## Linguagem
Java

## Entrada
A primeira linha contém um número inteiro N, que representa a quantidade de casos de teste. Em seguida, são informados N pares de números inteiros X e Y.

## Saída
Imprime o resultado da divisão de X por Y com uma casa decimal. Caso Y seja igual a zero, imprime "divisao impossivel".
